# Fossil

<img alt="Logo" src="graphics/icon.webp" width="120" />

**Fossil** is an Orubus liquid-glass launcher, modded from [Fossify Launcher](https://github.com/FossifyOrg/Launcher) (GPL-3.0).

**APP ID:** `app.orubus.fossil.launcher`

## What Fossil changes on top of Fossify Launcher

- **Liquid glass app drawer** — the drawer is a frosted translucent sheet with rounded top
  corners; the wallpaper behind it is blurred in real time on Android 12+ so the glass has
  real depth (graceful fallback on older devices).
- **Liquid glass settings** — settings live on a floating glass card over the blurred
  wallpaper instead of an opaque page.
- **App opening animation** — every launch gets a liquid bloom: the launched app scales in
  while the launcher sinks back for depth.
- **Grid customization** — home screen rows/columns (2–15 each), drawer columns (1–15),
  home & drawer label toggles, plus Fossify's full widget support.
- **Monochrome identity** — white-on-black icon set, `Fossil` branding, Orubus signing
  with a CI fingerprint gate.
